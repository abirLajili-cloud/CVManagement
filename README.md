# SkillFinder

Application CAP Node.js + SAPUI5 freestyle.

## Lancement

```bash
npm install
npm run deploy
npm run watch
```

Ouvrir `/skillfinder/index.html`.

Comptes locaux :
- admin@skillfinder.local / Admin123!
- user@skillfinder.local / User123!

Ces comptes sont uniquement destinés au développement local. Pour BTP, remplacer l'authentification mocked par XSUAA ou IAS.
